Offer Filter reads Dasher’s screen and offer notifications to apply your rules. Auto-accept is off by default. You can enable it with a separate confirmation in Settings; it can accept eligible matching offers and commit you to a delivery.

Automatic declines may dramatically lower your acceptance rate. Use the app only if you understand and accept that risk.

You do not need GitHub or any other account to download the app, receive signed updates, or send feedback.

  1. Use Download and setup for the current signed app. Keep Android’s security checks enabled; if a warning or restriction blocks installation, stop and check the guidance rather than bypassing it.
  2. Open Offer Filter and read the notice, including the acceptance-rate and account risks. Choose I understand and accept only if you agree.
  3. Use the app’s setup prompts for accessibility, notification access and its own notifications. Review each Android permission. Optional location is only for the offer map.
  4. Set your minimums, then use the mascot to start or pause filtering. Auto-accept is off unless you separately enable and confirm it. Inspect actual Dasher outcomes; an Accept request is not confirmation.
  5. Keep the app installed for automatic updates. Android may require permission for Offer Filter to install updates. Automatic installation waits for an observed dash end; Settings → Updates is a manual check.

Something isn’t right?

Pause with the mascot, turn off Auto-accept if enabled, and use Dasher directly. You can also disable Offer Filter’s accessibility and notification access in Android settings.
